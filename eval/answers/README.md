# Owner answer sheets (arm D and ablation Aa)

Arm D tests WhipUI *with* its elicitation step. Headless runs can't ask you questions,
so you answer the kickoff questions **before any output exists**, once per brief, in
`answers/<BRIEF_ID>.md`. These files are part of the pre-registration (hash them).

Answer briefly, in your own words (Thai or English), e.g. for B1:
- Who is it for / where do they come from?
- 1–3 sites, games or things whose *feel* you like, and what about them
- Anything you definitely don't want
- Must-haves (content, links, constraints)

Don't let the agent under test write these. If an arm D/Aa run has no sheet, the runner skips it.
