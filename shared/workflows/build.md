# Build the selected experience

1. Read the brief and actual stack, components, assets, tokens and callers. For
   existing UI read Garden `references/redesign-protocol.md`, identify extension,
   preserve or explicit overhaul, and protect routes/content/behavior/identity.
   Capture the relevant before state. A screenshot/Figma match uses the reference
   as visual authority; do not run a competing taste workshop. If a material
   product, flow or identity decision is unresolved, use design.md at that gap only.
   For game UI read [game.md](game.md) before choosing density/disclosure or
   changing scene/HUD/workspace behavior; preserve its simulation/input contract.

2. Choose the narrow expertise through SOURCE-MAP. New/unresolved identity follows
   design.md with Impeccable as the visual lead; an accepted direction is carried
   into implementation. Game UI Design owns player decisions; Game UI Frontend
   adapts browser UI and input/scene boundaries to the actual stack. Garden owns
   existing identity/fidelity. Pro Max retrieves a specific unanswered interaction,
   chart or stack question. A named expressive-web craft weakness can use relevant
   Taste sections or a compact frontend-design challenge, without restarting art
   direction. Scoped Impeccable actions address observed issues. No universal
   extra craft/audit pass or source default may replace approved intent, stack,
   dependencies or game information needs. Fetch primary API docs when necessary.

3. Build a viewable first slice early for a materially uncertain major composition.
   Use real content and assets where provided; label synthetic demonstrations and
   missing assets honestly. Present it for the unresolved owner decision rather
   than building a full speculative site. A precise brief or delegated one-shot
   continues autonomously. A feedback turn preserves all settled constraints and
   changes only the affected traits, flow, state or composition.

4. Implement executable components and states using the real platform conventions.
   Preserve semantic HTML/native semantics, labels, focus, keyboard/touch behavior,
   reduced motion, responsive layout and relevant loading/empty/error/recovery
   paths. Use Intent `fortify`/`include` for consequential resilience/access gaps;
   use Pro Max actual-stack guidance for a targeted implementation question.
   Motion explains action, hierarchy or narrative; never add a library/effect only
   because a retained source defaults to it. Image-first is conditional on the
   selected path and meaningful visual uncertainty, not every interface.

5. Run relevant build/checks, inspect the actual render and exercise the main
   journey. Follow review.md. For a selected Impeccable new-world or live method,
   finish its contract/review/documentation or event cleanup obligations and report
   any unavailable facility. Keep tool-derived records separate from editable truth.
   Stop at a verified useful artifact, not at compiling or producing DESIGN.md.
