# Reference sources by information need (not a universal search list)

This is a source **router**, not a gallery of reference styles. Access/API/licensing may change. Do not claim you searched sources you cannot access.

| User needs to understand | Look at | Retrieve |
| --- | --- | --- |
| Web interaction and layout patterns | Real product docs, live product sites, official design systems | Flow screenshots, states, interaction video where available |
| Expressive marketing/portfolio | [Awwwards](https://www.awwwards.com/), [SiteInspire](https://www.siteinspire.com/), [Godly](https://godly.website/), [Land-book](https://land-book.com/) | 2–4 contrasting styles, not derivative clones |
| App onboarding/paywall/settings flows | [Mobbin](https://mobbin.com/), [Appllama](https://www.appllama.io/), official app screenshots | Complete flow sequences, states, task order |
| Platform-specific accessibility / controls | [Apple HIG](https://developer.apple.com/design/human-interface-guidelines), [Material Design](https://m3.material.io/), [GOV.UK Design System](https://design-system.service.gov.uk/) | Tested components, interaction rationale and exceptions |
| Storytelling / game-world UI | Actual games, game patch sites, title screens and HUD captures (rights checked) | Mechanics of selection, hierarchy, feedback; no IP copying |
| Production implementation | Framework source, component libraries, open-source apps, official docs | Reusable architecture concepts, performance and state handling |
| Motion | Live sites, platform demos, recorded interactions, accessible reduced-motion alternatives | Trigger, temporal states, physical response, interrupt behavior |

For every retrieved example, annotate `source / accessed date / role / observed trait / what to transfer / what to reject / provenance rights`. Do not list screenshots as verified unless visually inspected. Do not silently bypass paywall or copy third-party artwork.
