# WhipUI

WhipUI is a thin frontend design router. It packages durable Project DNA,
Design Fingerprints, anti-slop rules, Pick from Web, and visual QA instructions
for existing Claude Code skills and MCP tools.

## Commands

    npm ci
    npm test
    npm run syntax-check
    npm pack --dry-run

## Architecture

- src/router.mjs routes five inputs to existing host capabilities.
- src/dna.mjs creates Project DNA from an existing repository.
- src/fingerprint.mjs creates Design Fingerprints and visual QA briefs.
- src/web-pick.mjs defines the Playwright-first Pick from Web contract.
- src/scaffold.mjs generates project-local agent instructions.
- templates/ contains the files generated by whipui init.
- .github/workflows/ci.yml verifies pushes and pull requests.
- .github/workflows/release.yml publishes tagged releases to npm.

## Claude Code integration

The local skill lives at .claude/skills/whipui/SKILL.md. Keep it thin and route
to skills and MCP servers that Claude already exposes. Do not add a new browser,
editor, agent runtime, or MCP server for ordinary frontend work.

## Release

Update the version with npm version patch, minor, or major. Push the commit and
tag. The release workflow runs tests, publishes the package, and creates the
GitHub release. The repository must have an NPM_TOKEN Actions secret.
