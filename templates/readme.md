# .whipui

This folder is generated by whipui init.

- project-dna.json is the durable product, repository, routing, and QA context.
- design-fingerprint.json is the visual identity record for a page or task.
- workflows/pick-from-web.md is the Playwright-first web element capture flow.
- workflows/visual-qa.md is the multi-axis browser review loop.
- examples/README.md contains natural-language examples for all five inputs.

The files are plain Markdown and JSON so any compatible coding agent can read
them without a WhipUI runtime plugin.
