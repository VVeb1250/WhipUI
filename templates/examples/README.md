# Natural-language workflows

No CLI routing command or design vocabulary is required after init.

## WhipUI

- "Recreate this card from the screenshot. Keep its typography."
- "Use this Figma frame for the settings page."
- "Open https://example.com and let me pick this navigation element."
- "Change the button radius to 8px. Keep everything else."
- "Use the existing components to add a matching settings page."

## WhipDesign

- "I want an app to track the books I read." No reference needed.
- "อยากได้เว็บจองเวิร์กชอป ใช้ง่ายและดูดี ช่วยคิดออกแบบให้เลย"
- "People get lost in checkout. Review the UX; keep the appearance and do not edit."
- "Suggest two approaches for onboarding. Do not build yet."
- "Make the visual design more distinctive but preserve the existing flow."

A source image does not override a UX-review request. A vague brief does not
authorize invented research or unlimited exploration. See evaluation.md for a
controlled comparison against the old workflow.
