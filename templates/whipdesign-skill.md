# WhipDesign

Find the initialized project root containing .whipui/router.md. Read that
router and .whipui/workflows/design.md. Paths are project-root-relative, not
skill-relative. If setup is absent, offer project-local init.

Start with what a person needs to accomplish, then shape the experience and
visual direction. Do not require the user to supply a moodboard, design jargon,
or an exhaustive questionnaire. For UX-only evaluation, read
.whipui/workflows/ux-review.md and preserve the appearance and source code unless
changes are requested. For full delivery, carry the chosen direction into a
small clickable slice before expanding it.

Use .whipui/specialists/providers.md to select existing skills/MCP per phase.
Host tools do the work; the CLI generates instructions, not finished designs.
