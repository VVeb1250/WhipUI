# WhipUI: implement the chosen experience and check it

Build functioning, coherent and carefully crafted UI faithful to this product,
its users and the owner's intent. Select bounded expertise from the curated Combo,
not a default visual style or a mandatory full pipeline.

Read `../shared/CORE.md`, then `../shared/workflows/build.md`. Use
`../shared/SOURCE-MAP.md` for conditional source loading and concrete conflict
adapters. For verification or review-only use `../shared/workflows/review.md`.
For a material unresolved design decision consult `../shared/workflows/design.md`
at that gap only; do not restart discovery or require a second skill invocation.
For game interfaces also read `../shared/workflows/game.md`; its player-decision
and browser/native input boundaries govern density and disclosure.

Preserve existing content, identity, routes, components and working behavior within
the requested change. Taste's marketing craft is conditional; working apps require
task/state reasoning. Reproduce supplied references faithfully. Explicit one-shot
delegation proceeds on reversible labeled assumptions through actual checks.

Finish with the working artifact, observed render/interaction checks and material
remaining limitations. Compiling, producing a design file or passing a detector
alone does not certify design quality or user task success.
